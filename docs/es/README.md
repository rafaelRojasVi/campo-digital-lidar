# Documentación en español — Campo Digital LiDAR

Esta carpeta contiene documentación destinada principalmente a la colaboración con Campo Digital y otros participantes de habla hispana.

La documentación técnica canónica del repositorio se mantiene principalmente en inglés. Esta carpeta no pretende duplicarla línea por línea.

## Documentos principales

### `estado-proyecto.md`

Resumen vivo del estado técnico del proyecto:

- qué problema estamos resolviendo;
- qué se ha demostrado;
- qué limitaciones conocemos;
- qué falta validar;
- cuál es el siguiente paso.

### `preguntas-campo-digital.md`

Preguntas abiertas que requieren información de Javier o del equipo de Campo Digital.

Debe actualizarse cuando aparezcan respuestas verificadas.

### `bitacora/`

Registro cronológico resumido del trabajo, problemas encontrados, hallazgos y decisiones.

## Regla de evidencia

En estos documentos se debe distinguir entre:

**Hecho confirmado:** observado directamente en datos, código, resultados reproducibles o información explícita entregada por Campo Digital.

**Inferencia:** interpretación respaldada por evidencia, pero todavía no demostrada directamente.

**Hipótesis:** idea que requiere experimentación o confirmación externa.

**Pregunta abierta:** información todavía necesaria.

## Terminología

Se pueden mantener términos técnicos habituales en inglés cuando aporten claridad, por ejemplo:

- point cloud (nube de puntos);
- ground truth (medición de referencia);
- return (retorno);
- ROI (región de interés);
- registration (registro/alineamiento);
- SLAM;
- LiDAR;
- LAS/LAZ;
- PDAL;
- CloudCompare.

La prioridad es mantener el significado técnico correcto.
